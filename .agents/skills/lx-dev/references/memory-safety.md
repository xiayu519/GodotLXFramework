# 内存安全

- `LifetimeScope` 拥有可释放服务和子作用域。
- `LX.Res` 返回的动态资源使用 `AssetLease<T>` 表示，必须显式释放或交给生命周期持有。
- 事件订阅必须通过所属生命周期解除。
- UI 激活处理器属于页面激活生命周期，反复开关不会重复订阅。
- 对象归还池前必须重置可复用状态。
- 长时间异步工作必须观察生命周期取消令牌。
- 世界、功能、区块和 UI 子树取得其动态实例所有者的生命周期。
- 缓存 UI 拥有稳定实例生命周期，每次打开使用新的激活生命周期。
- 等待式清理调用 `LXHost.ShutdownAsync`；同步 `_ExitTree` 仅作兜底。
- 重开闭环的诊断采样要等 UI/Feature handle 退出作用域和延迟释放帧完成，再与预热后的稳定基线比较；缓存策略允许保留实例，但不允许保留激活生命周期或动态租约。

Godot 场景自身持有的静态资源引用不需要资源租约。

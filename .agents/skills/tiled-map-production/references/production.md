# 素材与复用流程

## 从参考到生产约定

分析参考的投影与格子比例、角色/建筑尺度、光照方向、轮廓明暗、材质颗粒、色彩范围、密度和留白。输出可执行的风格约定，不复制原图的独特构图。参考存在坏切片时，先找到正确显示的对照；否则技术修复后明确标识，不将缺陷当画风。

先读取实际 TMX/TSX、图像尺寸和项目约定。所谓“斜 45 度”不足以确定逻辑格宽高或屏幕投影；128×64 是一种常用的 2:1 格形，不是所有等距地图的固定规格。保留 Tiled 的 orientation、tilewidth/tileheight、objectalignment 和 tileoffset；不要把对象坐标直接当作渲染坐标。正交与等距需要各自的原点和边界样例。

新制素材先完成小样：可相邻铺设的基础地面、一个重复道具、一个代表建筑，并检查相机、比例、光线和原点一致性。新增复杂结构时单独验证结构样例；仅修一个现有资源时不重新执行整套小样。

## 资产分工

| 种类 | 建议承担 | 避免 |
| --- | --- | --- |
| 基础地面 | 草地、土路、耕土、石面等材质 | 把可移动石头、花草、蔬菜烘到每格 |
| 接边/覆盖 | 材质接缝、岸线、窄路衔接 | 为整张地图每个位置独造地块 |
| 道具原型 | 单株作物、单节栅栏、石簇、单树 | 蔬菜整田烘焙、重复的近似切片 |
| 建筑/设施 | 可编辑实例及必要深度部件 | 为省拆件把桥面和近侧梁柱烘为一层 |
| 水面 | 静态底色/纹理和必要岸线 | 未要求就增加序列帧或引擎 shader |

自然地面可以含细小纹理噪点；接触阴影可随源物体保留。需要独立移动、交互、排序或大量复用的可识别物体才优先拆出。独特地标不必为提高复用率而强行重复。

材质组合不一定等于“区域数 × 4”：先共享基础材质，再按实际连接情况补接边。变体应解决明显重复纹理，而非掩盖布局问题。方向翻转须考虑光照、文字、门朝向及导入器变换支持，不能只为省图盲目镜像。

## 生成、清理与保真

生成指令明确投影、视角、尺寸/边缘约束、光照、单体或拼块职责，以及真实透明背景要求。逐个检查返回图像；棋盘格可能是烘入 RGB 的背景，不因为看起来像透明就接受。

本地技术裁切、透明遮罩、缩放与图集打包只在当前授权/工具规则允许时使用。不以“修切图”为由重画已认可像素。改共享原型后，查所有复用实例的原点、接地和遮挡。

`audit_alpha.py` 用 8 邻域统计 alpha 连通分量，默认保留任何 alpha > 0 的像素以发现浅残片；小分量只作为候选。散落叶片、栏杆部件、火花、阴影可以合法分离，不能默认只保留最大分量。先在深、浅和实际地面背景上看图，再决定修复遮罩。

保真拆件记录每件裁切原点与锚点。默认让每个可见源像素归属恰好一件，并以原 RGBA 重组逐像素对比，避免半透明边缘重复混合。若确需重叠或背面补绘，单独说明新增像素和合成规则，不再声称严格无损拆分。

## 编辑与来源

让地面、可复用道具和名称标签可以独立选择；共享 TSX 原型，不为每个对象复制文件。多部件结构说明一起移动、复制时的新关联 ID、旋转/缩放后的坐标更新要求。

交付包记录输入与输出指纹、来源/许可或生成记录、地图版本、原点和变换。生成器覆盖前对照上次生成指纹；人工改过的文件应合并或另建版本，不能静默重建。无需把旧大图塞进运行时图集；保真对照放在独立 source/reports 或历史包中。

统计分别列出地面、接边/水面和道具原型数量、已放实例数、唯一图像数、文件字节数。引用其他地图的共享图集不得只依据当前图的 unused 报告清理。证明“节省了一半”必须明确同口径前后值。

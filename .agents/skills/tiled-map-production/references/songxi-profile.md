# 松溪村：已验收案例与用户偏好

仅在用户要求延续松溪村、沿用这轮偏好或复查 V7 时读取。不是所有风格的默认规范，也不是素材授权文件。

## 本案例约定

- 中国古风村落、2:1 等距格形、自然色调和有细节的建筑/树木；风格一致性不是复制参考游戏的具体造型或布局。
- 资源复用优先于大量地块变化；保留合理地面，点缀单体摆放。作物与土床分离，菜摊与干货/山货摊商品不同。
- 默认只显示对应建筑的名称，不保留密集道具标签或玩法标记。
- 水面静态交付，后续由用户项目做流动 shader，不默认生成序列帧。
- 房屋按不可进入景物处理；不为了装饰增加可钻门洞。桥仅支持桥面通行，不做桥下层。
- 林角使用有层次的树群；公共树与井的位置按场景可用性安排。小摊合理贴屋或沿街，可接受局部遮挡。
- 地图变更未经再次明确授权，不提交或推送。过去对本地技术处理的允许不扩展到新任务或新素材。

# 按变化验证，不重复全量

## 选择范围

| 改动 | 必要证据 | 不默认执行 |
| --- | --- | --- |
| 名称标签/说明 | TMX 解析、目标标签/文字近景 | 引擎移动回归、生图 |
| 一张共享素材清理 | alpha/原点、保真对照、所有受影响实例检查 | 无关区域重新生成 |
| 道具摆放 | 目标区域构图；涉及入口则测相关通行 | 所有建筑回归 |
| 地面/图集/GID | TMX 资源审计、相邻接缝、原生 Tiled 导出、受影响区域渲染 | 真实模型评测 |
| 深度部件/碰撞/导入器 | 相关结构运行时行走、透明/实心像素、负对照；共享规则涉及的对象回归 | 与地图无关的框架全量验证 |
| 新整图交付 | 资源闭包、整图及重点近景、布局/通行、任务要求的运行时遮挡 | 发布导出、提交、推送 |

复用已经通过且输入未变的证据；以地图、TSX、图像、验证脚本和相关导入器指纹绑定结果。改变验证脚本会使相应旧结果失效。检查失败先修原因，不通过降低阈值、删除负对照、修改预期来让错误过关。

## 自带工具的精确范围

`audit_tmx.py` 使用 Python 标准库，只读 TMX/TSX 与引用文件：

- 检查外部/内嵌 tileset、图像、file 类型属性、GID 与动画帧引用。
- 支持 XML tile 数据、CSV、base64 无压缩/zlib/gzip、嵌套组与 infinite chunks；正确清除 GID 变换位。不支持 zstd、模板对象或非 TMX 输入时明确报错，不静默跳过。
- 分别统计各 tileset 的直接使用和动画闭包、空闲原型、实例和图像字节；比较图像文件 SHA-256，发现完全相同文件，不声称可检测所有视觉近似重复。
- PNG 尺寸按文件头和 TSX 声明核对；其他格式只确认文件存在。非图像外部 file 属性只做路径存在性检查，不递归解释其内部引用。
- `--asset-root` 只列出指定目录中未由此图引用的图像候选；包含共享素材或历史源图时不要据此删除。警告与错误分开。
- 无布局判断、碰撞、角色渲染或 alpha 检查。`pass=true` 仅针对上述结构范围。

`audit_alpha.py` 需要 Pillow，只分析指定图像的 RGBA 和 alpha 分量，报告小型分离候选，不修改像素、不判断候选必然有错，也不能识别所有与主体相连的脏边。用来定位后仍需看图。

```powershell
python <skill>/scripts/audit_tmx.py <map.tmx> --asset-root <delivery-assets>
python <skill>/scripts/audit_alpha.py <changed.png>
python <skill>/scripts/test_audits.py
```

不自动安装缺少的 Pillow。不支持的输入应使用项目已有读取器或 Tiled 原生转为受支持的**隔离副本**，并明确原图由原生工具验证；禁止原地改编码只为通过检查。

## 交付检查

1. 用实际 Tiled 解析/导出当前 TMX，检查 missing assets、GID、原点、比例和层次。资源包须独立可打开，或明确共享资源依赖及相对布局。
2. 目视整图与变化近景；不让大量对象标签掩盖问题，不把测试角色写进成品。
3. 执行所需运行时检查并记录引擎、导入器、地图指纹、路径和结果。引擎 ERROR 与失败退出不能被脚本自报 pass 覆盖。
4. 报告通过、警告、未验证内容，给出成品和证据位置。只有实际打开并确认版本后才说“已在 Tiled 打开”。

## 回归案例库

选与此次变化相关的案例，不每次全跑：合法分离叶片与非法残片的对照；缺少图片；错误 GID；稀疏 tileset ID；动画间接使用；被建筑遮住的交互面；栅栏缺口；村口旁路；桥侧梁漏遮、空隙误遮、桥端状态切换。新增投影或多人深度方案要增加代表样例，不把 V7 的通过数当成通用验证门槛。

早期宽泛入口会把无关功能带入上下文；用户因此要求按可独立请求的领域拆分。随后又澄清，反对的是无关 Skill，不是一次任务使用多个 Skill：真实跨域应组合完成交付所需的最小充分集合。

这条澄清用于避免把“语义隔离”误读成单 Skill 上限；当前触发边界和执行细则以负责的 Skill 为准。
